========================================
SITE DA MARIA JULIA 💗
========================================

ESTRUTURA:

site_maria_julia_v2/
│
├── index.html       -> página principal
├── index.php        -> declarações organizadas em PHP
├── style.css        -> todo o visual
├── script.js        -> toda a interatividade
└── assets/          -> pasta para imagens futuras


COMO ABRIR:

1. Extraia a pasta.
2. Você pode abrir o index.html diretamente no navegador.

IMPORTANTE:
A versão principal usa HTML + CSS + JavaScript e funciona
mesmo sem servidor.

O arquivo index.php fica separado para você poder usar PHP
quando quiser adicionar partes dinâmicas ao projeto.

SE FOR USAR PHP:

Com XAMPP:

1. Coloque a pasta em:
   C:\xampp\htdocs\

2. Ligue o Apache.

3. Acesse:
   http://localhost/site_maria_julia_v2/


ONDE EDITAR AS DECLARAÇÕES:

No index.html, procure os textos dentro do JavaScript
ou abra o script.js.

O index.php também possui todas as declarações organizadas
caso você queira futuramente transformar o projeto em um
site totalmente dinâmico com PHP.
